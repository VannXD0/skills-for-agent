# Baseline UI Correctness & Accessibility

Foundational rules for rock-solid web interfaces and user accessibility.

## Requirements
1. **WCAG 2.1 AA Compliance:** Minimum 4.5:1 contrast ratio for normal text, 3:1 for large text.
2. **Keyboard Focus Rings:** Every interactive element must provide visible, high-contrast focus rings.
3. **Semantic HTML5:** Use `<main>`, `<header>`, `<nav>`, `<section>`, `<article>`, `<button>` appropriately.
4. **Responsive Integrity:** Test at mobile (375px), tablet (768px), and desktop (1280px) breakpoints without horizontal overflows.
