# Impeccable Code Craft Benchmark

Standards for elegant, robust, and maintainable software engineering.

## Rules
1. **Single Responsibility:** Design clean module boundaries with minimal coupling.
2. **Zero Dead Code:** Eliminate commented-out blocks, unused imports, and speculative helper functions.
3. **Strict Typing:** All public API signatures must have concrete type definitions.
4. **Minimal Blast Radius:** Touch only the exact lines and files needed to resolve the request.
