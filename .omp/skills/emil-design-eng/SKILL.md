# Emil Design Engineering Discipline

Brings production design engineering standards and natural physics to web components and user interfaces.

## Core Rules
1. **Spring Physics:** Use natural physics-based curves (`cubic-bezier(0.16, 1, 0.3, 1)`) instead of linear or abrupt transitions.
2. **Interaction Boundaries:** Maintain feedback on hover, active, and focus states.
3. **Micro-Interactions:** Ensure smooth state transitions without layout thrashing.
4. **Spatial Restraint:** Respect content flow; never crowd interactive elements.
