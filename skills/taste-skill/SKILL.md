# Taste Skill — Aesthetic Judgment & Calibration

Enforces high-craft visual standards eliminating generic template aesthetics.

## Principles
1. **Typographic Personality:** Reject browser fallback sans-serifs; pair distinctive display type with clean monospace or serif data elements.
2. **Chromatic Restraint:** Build around high-contrast surfaces (`#0A0B0E`, `#0D0E12`) with a single deliberate accent color.
3. **Intentional Asymmetry:** Break repetitive card grids with varied span ratios (`col-span-8` vs `col-span-4`) to guide optical hierarchy.
